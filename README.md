# Nguyên lý kế toán – Luyện tập

Ứng dụng luyện tập môn Nguyên lý kế toán chạy trực tiếp trên trình duyệt (một file `index.html`, không cần cài đặt).

- Bài tập LMS (Chương 1–6) và Bài tập khác (các đề ôn)
- Trộn câu hỏi, trộn đáp án, đánh dấu, ôn lại câu sai
- Ôn tập lý thuyết: đọc, flashcard, công thức theo từng chương

Tiến độ được lưu trong trình duyệt của mỗi người. Một số đáp án do tự giải (có ghi chú trong phần lời giải), hãy đối chiếu với giảng viên khi cần.
